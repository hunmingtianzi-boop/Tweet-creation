## 使用方法

1. 在 Ardot 正文链接中继续编辑 390 px 文章根节点；六个章节都保持为独立 Frame，便于调整与导出。
2. 小插图来自同页的四个可复用组件源，分别承担开场锚点、章节转场、正文解释和结尾收束；不要把它们替换成随机 AI 装饰。
3. 活动、人物和成果只能使用组织提供的真实照片；生成底图只负责连续氛围，不冒充现场。
4. 补齐正式报名日期、报名二维码和咨询方式后，替换 CTA 中三个明确标记为“待补”的内容。
5. 再运行视觉验收与发布检查；二维码只接受组织提供的官方文件，不自动生成。

## 迁移到其他公众号

复制本工程时，应先用该组织的定位、受众、历史内容和真实素材重新建立独立 organization pack，再重新完成视觉校准、master/companion 底图和四种文章专属微组件。正文结构可以复用，品牌资产和视觉表达不能直接照搬拓浙 AI 生态。
